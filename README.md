# 장기흥 (KeeHeung Jang)

게임 클라이언트/서버 개발자 · 웹 게임 상용 서비스를 개발하고 있고, UE5로 전투 프로토타입을 만들고 있습니다.
문제의 원인은 추측 대신 실측으로 확인하고, AI와 함께 만든 코드도 동작 원리를 이해하고 검증한 것만 채택하려고 합니다.
